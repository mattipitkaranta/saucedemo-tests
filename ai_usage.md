# AI usage

- I used OpenAI Codex as a coding agent to set up the project, explore the application, generate and run tests, and fix technical issues.
- I used ChatGPT separately to discuss architecture, refine prompts, and review implementation approaches.
- I manually reviewed and approved the test scenarios, inspected the generated code, and used VS Code's debugger to step through test execution and verify application behavior.
- I used `AGENTS.md` to document shared development conventions, quality rules, and constraints for future contributors using AI agents.

AI assisted with implementation. I retained responsibility for test design decisions, code quality, and final validation.
